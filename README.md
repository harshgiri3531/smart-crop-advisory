# 📌 Overview

Smart Crop Health Advisory is an **AI + Machine Learning based agricultural advisory system** that predicts crop health and expected yield using **NDVI (Normalized Difference Vegetation Index)** values.

The system analyzes vegetation health from NDVI input values between **0.0 to 1.0** and intelligently classifies crop conditions into:

- 🌱 Healthy
- 🟡 Moderate
- 🔴 Stressed

It also provides:
- 📈 Yield Prediction
- 🤖 AI Farming Assistant
- 🌾 Smart Farmer Advisory
- 🧠 AI-generated crop suggestions using Groq LLM

---

# ✨ Key Features

## 🌿 NDVI-Based Crop Health Prediction
Predict crop condition using NDVI values.

| NDVI Range | Crop Status |
|------------|-------------|
| 0.6 - 1.0 | 🌱 Healthy |
| 0.3 - 0.6 | 🟡 Moderate |
| 0.0 - 0.3 | 🔴 Stressed |

# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/harshgiri3531/smart-crop-advisory.git
```

---

## 2️⃣ Move into Project Folder

```bash
cd smart-crop-advisory
```

---

## 3️⃣ Install Required Packages

```bash
pip install -r requirements.txt
```

---

## 4️⃣ Set Environment Variable

### PowerShell

```powershell
$env:GROQ_API_KEY="your_api_key_here"
```

---

## 5️⃣ Run Flask Application

```bash
python project.py
```
